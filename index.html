Projects

Catalog Mismatch Checker

A Python tool that compares retailer and seller product data and flags differences in title, brand, color and price. It exports an Excel report by mismatch type and category. On sample data (2,000 items), it found 403 items with at least one mismatch, so accuracy was 79.6%. Price errors averaged 13.5% off, and Apparel had the highest error rate at 23.1%.

  • Python
  • pandas
  • Excel
  • Root-cause analysis

A BRD for a tool that monitors catalog accuracy. It covers the problem, goals and success metrics, stakeholders, functional requirements, user stories and a process flow. The target is to raise accuracy from 79.6% to 95% and cut manual QC time by half.
